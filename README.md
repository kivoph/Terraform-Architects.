# Terraform Architects website

Static site (no build step).

- `index.html` – the website
- `assets/` – logo, project photos, walkthrough video + poster
- `vercel.json` – cache settings

## Deploy
1. Upload everything in this folder to a GitHub repo (keep the `assets` folder).
2. Vercel > Add New > Project > import the repo > Framework Preset: **Other** > Deploy.
